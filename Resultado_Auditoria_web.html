Top 5 Problemas Críticos

1. Sitemap Completamente Roto (404 en todas las rutas)

CRÍTICO

Impacto: Google y Bing no pueden descubrir páginas a través del sitemap. Afecta la indexación de nuevos productos.

El archivo sitemap_index.xml referenciado en robots.txt devuelve 404. Se probaron estas rutas:

  • /sitemap_index.xml → 404
  • /product-sitemap.xml → 404
  • /category-sitemap.xml → 404
  • /page-sitemap.xml → 404
✓ SOLUCIÓN (5 minutos):
  1. Acceder a WordPress admin panel
  2. Ir a Rank Math > Sitemap Settings
  3. Confirmar que "Enable Sitemap" está activado
  4. Ir a Settings > Permalinks
  5. Hacer click en "Guardar cambios" (sin cambiar nada)
  6. Verificar que https://orquideasgarden.store/sitemap_index.xml ahora retorna un documento XML válido
  7. Resubmitir el sitemap en Google Search Console

2. Meta Descripciones Ausentes en el 100% de Páginas

CRÍTICO

Impacto: Sin meta descripciones, Google genera fragmentos automáticos de baja calidad que reducen el CTR (Click-Through Rate). Se pierden oportunidades de controlar cómo aparece el sitio en resultados de búsqueda.

Se rastrearon 19 páginas. 0 de 19 tienen meta descripción. Esto incluye:

  • Homepage
  • Todas las categorías (/tienda/, /orquideas-classic/, /condolencias/, /luxury/, /cromadas/, /sembrados-garden/, /fechas-especiales/, /personalizados/)
  • Todas las páginas de productos
  • Páginas legales (/aviso-de-privacidad/, /terminos-y-condiciones/, etc.)
✓ SOLUCIÓN (2-3 horas):
  1. En WordPress admin, abrir Rank Math > Titles & Meta
  2. Escribir meta descripciones únicas de 150-160 caracteres para cada página:
    • Homepage: "Orquídeas Phalaenopsis premium, arreglos florales y regalos especiales con envío a domicilio en Bogotá y Colombia. ¡Pide ahora por WhatsApp!"
    • /tienda/: "Compra orquídeas elegantes, arreglos florales para condolencias, cumpleaños y ocasiones especiales. Entrega nacional en Colombia."
    • Categorías de productos: Descripción única para cada línea con keyword principal + CTA
  3. Usar Rank Math > Bulk Title & Meta para aplicar patrones a múltiples páginas

3. Sin Schema / Datos Estructurados en Páginas de Producto

CRÍTICO

Impacto: Sin schema Product, no aparecen Rich Results (precio, disponibilidad, estrellas) en Google. Pierdes posiciones en búsquedas comerciales y no diferencias tus productos de la competencia.

Se buscó schema en todas las páginas rastreadas. Hallazgos:

  • ❌ Sin Product schema en ningún producto
  • ❌ Sin FAQPage schema
  • ❌ Sin BreadcrumbList schema
  • ❌ Sin LocalBusiness o Florist schema en homepage
  • ✓ Schema Florist + Organization básico presente, pero no configurado óptimamente
✓ SOLUCIÓN (1-2 horas):
  1. En WordPress admin, ir a Rank Math > Schema > Products
  2. Activar "Product" schema e ingresarle Rank Math auto-mapee WooCommerce fields (nombre, precio, descripción, imagen)
  3. Confirmar que cada producto tenga al menos una imagen (para schema)
  4. Verificar en Google Rich Results Test que cada producto ahora muestre precio, disponibilidad e imagen
  5. Agregar schema BreadcrumbList en categorías para mejorar navegación

4. Email de Contacto Inválido (.local Domain)

CRÍTICO

Impacto: Máxima severidad para confianza. El email info@orquideasgarden.local es un dominio local de desarrollo que no existe en internet. Los clientes no pueden contactarte y Google penaliza sitios con información de contacto inválida.

Ubicación del error: Footer del sitio y probablemente en páginas de contacto.

✓ SOLUCIÓN (5 minutos):
  1. En WordPress admin, ir a Divi > Theme Options > General
  2. Buscar campo de email de contacto
  3. Cambiar de: info@orquideasgarden.local
  4. Cambiar a: info@orquideasgarden.store (o un email real funcional)
  5. Guardar cambios
  6. Verificar que todos los formularios de contacto usen la dirección correcta

5. Headers de Seguridad Críticos Ausentes

CRÍTICO

Impacto: El sitio expone vulnerabilidades a XSS, clickjacking y MIME sniffing. La versión de PHP es visible públicamente. Además, es una señal negativa de confianza para usuarios y motores de búsqueda.

Headers encontrados como faltantes:

  • ❌ X-Content-Type-Options: nosniff
  • ❌ X-Frame-Options: SAMEORIGIN
  • ❌ Strict-Transport-Security (HSTS)
  • ❌ Content-Security-Policy
  • ❌ Referrer-Policy
  • ⚠️ X-Powered-By: PHP/8.3.30 — expone versión (debe removerse)
✓ SOLUCIÓN (15 minutos):

Editar el archivo .htaccess en la raíz del servidor (vía FTP o cPanel File Manager) y agregar:

<IfModule mod_headers.c>
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
    Header always set Referrer-Policy "strict-origin-when-cross-origin"
    Header unset X-Powered-By
    Header unset Server
</IfModule>

Guardar. Verificar con: curl -I https://orquideasgarden.store

Problemas de Alta Prioridad

Viewport Meta Tag Bloquea Zoom de Usuarios

ALTO

Ubicación: <head>

Código actual:

<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=0">

Problema: maximum-scale=1.0 y user-scalable=0 previenen que usuarios (especialmente con baja visión) hagan zoom. Google ha señalado esto como problema de accesibilidad.

✓ Cambiar a:
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Ubicación: Divi Theme Options > General > Viewport Meta Tag

URLs Duplicadas (Con/Sin Trailing Slash)

ALTO

Ejemplos encontrados:

  • /condolencias y /condolencias/
  • /orquideas-classic y /orquideas-classic/
  • /sembrados-garden y /sembrados-garden/

Problema: Desperdician presupuesto de rastreo (crawl budget) y pueden causar pérdida de PageRank.

✓ Solución:

Auditar todos los links internos en Divi y en los menús de navegación. Estandarizar TODOS a usar trailing slash (/categoria/) que es el estándar de WordPress. Usar plugin Redirection para confirmar que las versiones sin slash redirigen correctamente a las versiones con slash.

El Mayor Gap: Contenido Citable

Los sistemas de AI citan contenido cuando encuentran bloques de 134-167 palabras con respuestas directas al inicio de secciones. Actualmente:

  • ❌ Ningún bloque de texto supera 30 palabras en la homepage
  • ❌ No hay preguntas en los headings (H2/H3)
  • ❌ No hay contenido FAQ o How-To
  • ❌ No hay schema FAQPage o HowTo
  • ❌ Descripciones de producto: solo nombre + precio (0 palabras de especificación)

Impacto: El sitio es "invisible" para sistemas de AI que buscan respuestas textualmente extraíbles. No aparece en Google AI Overviews, ChatGPT, Perplexity, etc.
