Contexto del Proyecto

Orquídeas Garden S.A.S. busca evolucionar su presencia digital hacia un posicionamiento premium, enfocado en exclusividad y empaques sofisticados. Actualmente operan en WordPress + WooCommerce con una puntuación SEO de 48/100.

Se identificaron tres problemas clave que justifican el cambio de estrategia:

  • WordPress + Divi + WooCommerce genera una experiencia visual lenta y poco diferenciada
  • Shopify, como alternativa evaluada, tiene un fee mensual que no es viable para el modelo de negocio actual
  • El diseño actual no comunica el nivel de exclusividad que el catálogo de productos merece

Solución propuesta: Landing pages premium independientes por producto/colección, con animaciones scroll de alto impacto, redirigiendo el proceso de pago a WooCommerce (ya configurado y funcional).

Recomendación Final

Framer para arrancar.
Next.js para escalar.

Dado que el objetivo es lanzar rápido con impacto visual premium sin depender de un desarrollador disponible, Framer es la elección más pragmática para el primer sprint.

Crear la primera landing con Framer en 3-7 días permite validar el concepto visual premium y el flujo de pago hacia WooCommerce. Una vez validado el modelo, migrar el diseño a Next.js + GSAP para eliminar el costo mensual y maximizar el SEO.

La fotografía del packaging es la inversión más importante. Sin imágenes de estudio sobre fondo neutro, ninguna tecnología generará el impacto de marca premium buscado.

Identidad Visual Premium

Elementos que deben acompañar cualquier alternativa tecnológica elegida

📸

Fotografía

Fondo negro o crema neutro, iluminación de estudio, packaging como protagonista. Sin imágenes de WhatsApp.

🔤

Tipografía

Cormorant Garamond o similar serif para titulares. Inter o Neue Haas para cuerpo. Nunca mixtos genéricos.

🎨

Paleta de Color

Negro profundo + dorado cálido + crema. Abandonar el verde genérico que usan todas las florerías.

Roadmap de Implementación

Plan de ejecución recomendado por fases

Semana 1–2 — Mientras sigue en WordPress

Correcciones Críticas

  • Arreglar sitemap roto (5 minutos en WordPress)
  • Corregir email de contacto (.local → .store)
  • Agregar meta descripciones a las 19 páginas rastreadas
  • Configurar schema Product en Rank Math para WooCommerce

Semana 2–3 — Sesión de fotografía

Activo Visual Premium

  • Sesión fotográfica de estudio: packaging + producto sobre fondo neutro
  • Video corto de unboxing para uso en landing y redes
  • Fotografía de detalle: pétalos, empaques, lazos, presentación
  • Sin este paso, ninguna tecnología generará el impacto deseado

Semana 3–4 — Primera Landing Premium

Lanzamiento con Framer

  • Elegir colección estrella (recomendado: Luxury o Supreme)
  • Diseñar y publicar primera landing premium en Framer
  • Conectar CTA → redirect a WooCommerce para el pago
  • Validar el flujo completo con pedido de prueba

Mes 2 — Escalado

Landing por Colección + Migración Técnica

  • Crear landing individual para cada colección (Classic, Condolencias, Cromadas, Sembrados)
  • Evaluar migración a Next.js + GSAP si se requiere eliminar el costo mensual de Framer
  • Crear guía de cuidado de orquídeas (contenido citable para AI search)
  • Lanzar canal YouTube con videos de unboxing y cuidado
