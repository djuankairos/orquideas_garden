## Diagnostico y Correcciones - Auditoría de animaciones
**Problema identificado:** Animación estática a pesar de código correcto

### Causas encontradas:
1. **CSS `visibility: hidden`** bloqueaba frames de animación
   - Solución: Reemplazado por `opacity: 0` con `pointerEvents: none`
2. **Clase arbitraria `[perspective:1000px]`** podría no compilarse
   - Solución: Movida a `style={{ perspective: "1200px" }}` inline
3. **`transition-all` con `visibility`** causaba corte de frames
   - Solución: CSS transitions específicas para `transform`, `opacity`, `filter`
4. **Bug en cálculo de posición** con número par de imágenes
   - Solución: Fórmula mejorada `pos = ((index - currentIndex) % total + total) % total`
5. **CSS transitions puras limitadas**
   - Solución: Migración a **Motion/React** para animaciones interpoladas

### 2. Botón de WhatsApp en Cotización NO ENVÍA FORMULARIO
- **Problema:** El formulario de cotización no pre-rellena el mensaje en WhatsApp
- **Causa posible:**
  - El enlace se abre pero sin los datos capturados del formulario
  - La función `buildWhatsAppUrl()` puede no estar capturando valores correctamente
  - El método programático de crear/clickear elemento anchor puede no funcionar en todos los navegadores
- **Ubicación:** `components/cotizacion-form.tsx`
- **Impacto:** El usuario debe escribir manualmente toda la información en WhatsApp
- **Próximo paso:** Revisar consola de navegador para errores, validar que FormData captura datos, probar en diferentes navegadores
